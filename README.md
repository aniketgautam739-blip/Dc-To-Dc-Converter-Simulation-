# Optimising DC–DC Converter Efficiency Through Simulation

**Project Type:** Independent Engineering Project  
**Field:** Electrical Engineering | Power Electronics  
**Simulation Software:** LTspice

## 1. Project Overview

This project explores the design and simulation of a DC–DC buck converter intended to step down a 12V DC input to approximately 5V DC.

Using LTspice, I investigated the converter's behaviour under different duty-cycle conditions, examining output voltage characteristics, transient response, and switching behaviour.

The project was undertaken to develop a deeper understanding of power electronics and the practical principles behind efficient DC voltage conversion.

## 2. Project Objectives

- Design and simulate a step-down DC–DC buck converter.
- Investigate the relationship between duty cycle and output voltage.
- Analyse output voltage stability and transient response.
- Examine switching waveforms and circuit behaviour.
- Understand the factors influencing converter performance.

## 3. Tools and Technologies

## 5. Simulation Methodology

The converter was simulated using a 12V DC input with an intended output of approximately 5V.

Different duty-cycle values between 0.3 and 0.6 were investigated to observe their influence on output voltage and circuit response.

The simulation included transient analysis and examination of voltage waveforms.

## 6. Results and Analysis

The simulation produced an average output voltage of approximately 4.9V under the investigated operating conditions.

Further analysis examined:

- Output voltage behaviour.
- Duty-cycle variation.
- Transient response.
- Voltage overshoot.
